# 📊 Dashboard E-commerce com Python e Dash

Este projeto consiste em um dashboard interativo para análise de dados de e-commerce,
desenvolvido com **Python**, **Pandas**, **Plotly** e **Dash**.

O objetivo é explorar informações de produtos, preços, avaliações e volume de vendas,
auxiliando na tomada de decisões estratégicas.

---

## 🚀 Funcionalidades

- Análise da relação entre **preço e nota dos produtos**
- Visualização da **média de avaliações por marca**
- Distribuição de preços dos produtos
- Quantidade de produtos vendidos por marca
- **Filtro interativo por gênero**, com atualização dinâmica dos gráficos

---

## 🧠 Insights Possíveis

- Identificar se produtos mais caros possuem melhores avaliações
- Comparar marcas com melhor percepção dos clientes
- Analisar quais marcas vendem mais dentro de cada gênero
- Apoiar decisões de **precificação** e **mix de produtos**

---
