# 📊 Dashboard E-commerce com Dash

Este projeto apresenta um dashboard interativo desenvolvido em Python utilizando **Dash** e **Plotly**, com dados reais de produtos de e-commerce.

## 🚀 Tecnologias
- Python
- Pandas
- Dash
- Plotly

## 📁 Estrutura
- `app.py` → aplicação Dash
- `ecommerce_estatistica.csv` → base de dados
- `requirements.txt` → dependências

## ▶️ Como executar o projeto

```bash
pip install -r requirements.txt
python app.py
